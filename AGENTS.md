# trocabikes

## Stack

Laravel 13 / Inertia 3 / React 19 / Tailwind CSS 4 / Pest 4. Dev uses MySQL (Docker). Tests use `RefreshDatabase` (Feature tests only). Sessions, cache, and queue use database driver. Font: Instrument Sans (via `bunny()` loader).

## Commands

| Purpose | Command |
|---|---|
| Dev server (4 concurrent: serve, queue, logs, Vite) | `composer dev` |
| Run all tests | `php artisan test --compact` |
| Single test | `php artisan test --compact --filter=testName` |
| PHP lint (Pint) | `composer lint` |
| JS lint (ESLint) | `bun run lint` |
| Format (Prettier) | `bun run format` |
| Type check (tsc --noEmit) | `bun run types:check` |
| Full CI (lint → format → types → Pint → test) | `composer ci:check` |
| Fresh setup (composer+bun+key+migrate+build) | `composer setup` |
| Regenerate Wayfinder types | `php artisan wayfinder:generate` |

**Note**: Package manager is **Bun**, not npm. Dockerfile installs Bun (no Node.js). Run `bun install` and `bun run <script>`.

## Docker

- `docker compose up` starts app (port 8000) + MySQL 8.0 (port 3306).
- MySQL has no password (`MYSQL_ALLOW_EMPTY_PASSWORD=yes`). DB name: `trocabikes`.
- Bun is installed at `/root/.bun/bin` in the container. If `bunx` is not found, rebuild: `docker compose build`.

## Domain

Models with factories: `User` (SoftDeletes), `BikeBrand`, `BikeCategory`, `Listing` (belongs to user/brand/category). Enums: `FrameMaterial`, `ListingCondition`, `ListingStatus`. Observers: `BikeBrandObserver`, `BikeCategoryObserver` (auto-slug generation).

## Style

- **PHP**: run `vendor/bin/pint --format agent` after changes (Pint preset: `laravel`).
- **JS**: ESLint enforces `@typescript-eslint/consistent-type-imports` (separate type-imports), `import/order` (builtin→external→internal→parent→sibling→index, alpha asc), `@stylistic/padding-line-between-statements` around control flow, `curly` (all). Prettier: `tabWidth: 4`, `singleQuote: true`, `semi: true`, `prettier-plugin-tailwindcss` with `clsx`/`cn`/`cva` tailwindFunctions.
- **Class composition**: `cn()` from `@/lib/utils` (clsx + tailwind-merge). Variants: `class-variance-authority`.
- **React Compiler** enabled via `babel-plugin-react-compiler` in Vite config.

## Path aliases

Both `@/*` and `~/*` resolve to `resources/js/*`.

## Generated code (do not edit)

`resources/js/actions/`, `resources/js/routes/`, `resources/js/wayfinder/` are auto-generated by Wayfinder (`formVariants: true`). Import from `@/actions/` and `@/routes/` instead of hardcoded URLs. ESLint ignores these directories.

## Testing

- Pest 4. `RefreshDatabase` applied globally to `Feature` tests only (see `tests/Pest.php`).
- Use factories for model creation. All feature tests use `RefreshDatabase`.
- Create tests: `php artisan make:test --pest {name}` (no suite prefix in name).
