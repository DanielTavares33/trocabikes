# trocabikes

## Stack

Laravel 13 / Inertia 3 / React 19 / Tailwind CSS 4 / Pest 4. Dev uses MySQL (Docker). Tests use SQLite `:memory:`. Sessions and cache use database driver. Single route (`/` → `welcome` name `home`).

## Commands

| Purpose | Command |
|---|---|
| Dev server (4 concurrent: serve, queue, logs, Vite) | `composer dev` |
| Run all tests | `php artisan test --compact` |
| Single test | `php artisan test --compact --filter=testName` |
| PHP lint (Pint) | `composer lint` |
| JS lint (ESLint) | `npm run lint` |
| Format (Prettier) | `npm run format` |
| Type check (tsc --noEmit) | `npm run types:check` |
| Full CI (JS lint → format check → types → Pint → test) | `composer ci:check` |
| Fresh setup (composer+npm+key+migrate+build) | `composer setup` |
| Regenerate Wayfinder types | `php artisan wayfinder:generate` |

## Domain

Models with factories: `User` (SoftDeletes), `BikeBrand`, `BikeCategory`, `Listing` (belongs to user/brand/category). Enums: `FrameMaterial`, `ListingCondition`, `ListingStatus`. Observers: `BikeBrandObserver`, `BikeCategoryObserver` (auto-slug generation). All feature tests use `RefreshDatabase`.

## Style

- PHP: run `vendor/bin/pint --format agent` after changes (Pint preset: `laravel`).
- JS: ESLint enforces `@typescript-eslint/consistent-type-imports` (separate type-imports), `import/order` (builtin→external→internal→parent→sibling→index, alpha asc), `@stylistic/padding-line-between-statements` around control flow, `curly` (all). Prettier: `tabWidth: 4`, `singleQuote: true`, `semi: true`, `prettier-plugin-tailwindcss` with `clsx`/`cn`/`cva` tailwindFunctions.
- Class composition: `cn()` from `@/lib/utils` (clsx + tailwind-merge). Variants: `class-variance-authority`.
- React Compiler enabled via `babel-plugin-react-compiler` in Vite config.

## Generated code (do not edit)

`resources/js/actions/`, `resources/js/routes/`, `resources/js/wayfinder/` are auto-generated by Wayfinder (`formVariants: true`). Import from `@/actions/` and `@/routes/` instead of hardcoded URLs.
